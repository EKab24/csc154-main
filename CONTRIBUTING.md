# Contributing to CSC-154

This repository is a shared course workspace. Follow these guidelines unless an assignment gives you different instructions.

## Branches

- Create your own branch before making course changes.
- Use a short, descriptive branch name.
- Do not make changes directly on `main` unless instructed.

Example branch names:

```text
jason-module1
jsmith-module2
fix-readme
```

## Commits

Write commit messages that briefly describe what changed.

Good examples:

```text
Add Module 1 introduction
Complete Git workflow practice
Update README instructions
```

Avoid vague messages such as:

```text
stuff
changes
final
final2
```

## Shared Work

- Do not delete or overwrite another student's work unless the assignment specifically requires it.
- Check which file and folder you are working in before committing.
- Ask before making broad changes to shared files.

More detailed Issue, Pull Request, review, and merge requirements will be added later in the course.
